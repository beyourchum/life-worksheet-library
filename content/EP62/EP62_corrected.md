# Ep.62 這點薪水憑什麼要我拚？｜Z世代整頓職場，談談努力與回報的交換關係

**學習目標：** 釐清工作中的努力、回報與成長，找出自己的職場底線，想一個下一步。

**使用說明：** 這份學習單會帶你整理工作帶來的回報、自己投入的成本與成長，再想想目前適合繼續觀察、溝通，還是開始找下一份工作。可以自己完成，也可以和輔導員一起討論；沒有標準答案。

請先勾選目前的感受。

- 目前的薪水
- 目前的工作內容
- 目前的工作環境
- 目前的同事關係
- 目前的通勤距離
<!-- end-matrix -->

- [ ] 其他（請填寫）

- [ ] 人脈或口碑

## 03 我的職場底線

### 下列哪些情況是我不能長期接受的？（可複選）

- [ ] 薪水和付出差距太大
- [ ] 工作內容和原本約定不同
- [ ] 工時、休息或排班讓生活難以負擔
- [ ] 缺少安全感或基本尊重
- [ ] 通勤或其他成本太高
- [ ] 其他（請填寫）

## 04 我接下來想怎麼做？

### 我目前比較想怎麼做？（單選）

- [ ] 先繼續觀察並記錄
- [ ] 和主管或相關的人溝通
- [ ] 開始找下一份工作
- [ ] 還不確定，先找人討論

### 我接下來的一小步是（可複選）

- [ ] 記錄工作內容、薪水或工時
- [ ] 整理想溝通的重點
- [ ] 查詢相關的工作權益
- [ ] 更新履歷或看看職缺
- [ ] 找信任的人討論
- [ ] 其他（請填寫）
