# Ep.113  400年前，誰才是迷信的人？｜神諭、科學、AI，誰有資格定義理性？

**學習目標：** 學習理性求助

## 一、卡住的時候我會求助⋯⋯

- [ ] 算命玄學類：看星座運勢、抽塔羅牌、算八字

- [ ] 網路權威類：上 YouTube 看網紅/KOL 的分析、看 threads

- [ ] 現代科技類：打開 ChatGPT 或 AI，要它幫我分析是誰的問題

- [ ] 機率命運類：丟硬幣、求籤

- [ ] 其他：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

## 二、我是理性的嗎？

請從以下面向檢核

如果我選錯了，代價大嗎？

- [ ] 我已經仔細評估過這個決定「最壞的結果」是什麼，而且確定自己可以承擔。(3分)

- [ ] 我大概知道選錯了會有什麼影響，但還沒完全想好退路。(2分)

- [ ] 我完全不知道選錯會怎樣，也不想去思考後果，只希望有人能趕快給我一個答案，結束這種煩躁感。(1分)

在現實中，我能看到什麼徵兆？

- [ ] 我已經設定好具體的「觀察條件」。如果別人給我建議，我會去觀察現實生活中的證據（例如：對方實際的行動，而不是只聽他說）(3分)

- [ ] 我有一個模糊的感覺，覺得接下來應該要注意某些事，但還沒有具體寫下要在現實中觀察什麼。(2分)

- [ ] 我完全沒有想到要在現實中觀察什麼，打算走一步算一步，或者對方（或 AI）說什麼我就信什麼。(1分)

我自己先想過了嗎？

- [ ] 選項的優缺點我都已經認真比較過了！我只是分析到了極限，需要一個外力幫我做最後的決定。(3分)

- [ ] 我腦中有大概想過，但還沒有認真整理清楚，思緒有點亂，想要聽聽別人的意見再來想。(2分)

- [ ] 我完全不想動腦，大腦一片空白，希望直接有人告訴我該怎麼做，照著做就好。(1分)

我是想找答案，還是只想找人附和？

- [ ] 我抱持開放的心態，不管對方（或 AI）給的建議是不是我愛聽的，我都願意客觀參考。(3分)

- [ ] 我心裡其實已經有一個偏好的答案，希望求籤或算命能給出一樣的答案來支持我。(2分)

- [ ] 我只是一直在網路上尋找「跟我心裡想的一樣」的答案，如果結果不順我的意，我就換一個再算一次。(1分)

這個答案真的專屬於我嗎？

- [ ] 我能分辨出對方講的話是不是「套在每個人身上都說得通」的客套話，我只會挑選對我具體有用的部分。(3分)

- [ ] 我覺得對方的解釋「有一點點像在說我」，但我不太確定它能不能解決我眼前的具體問題。(2分)

- [ ] 我覺得網紅/算命師講的話「完全就是在說我！他懂我！」，並且決定把他說的每一句話都當成真理。(1分)

這個方法會讓我失去什麼嗎？

- [ ] 我尋求解答的管道是免費或小額的，而且就算我不聽他的建議，我的生活也不會有任何損失。(3分)

- [ ] 這個管道可能需要花費一些金錢購買開運小物或課程，我正在猶豫。(2分)

- [ ] 這個管道要求我付出大量金錢、斷絕跟朋友家人的聯絡，或者告訴我「外界的質疑都是迫害、只有他們掌握真相」(1分)

這個答案是讓我變積極，還是變消極？

- [ ] 我知道不管玄學或 AI 怎麼說，聽完之後我還是會自己決定接下來要「採取什麼行動」。(3分)

- [ ] 聽完答案後，我覺得心情比較平靜，但對於實際該怎麼做，還是有一點茫然。(2分)

- [ ] 聽完答案後，我會變得被動，不去思考或觀察，一直說服自己相信答案。(1分)

我到底該問神，還是問當事人？

- [ ] 這件事如果牽涉到別人（如伴侶、朋友、老闆），我已經準備好，或已經嘗試直接跟對方溝通了。(3分)

- [ ] 我還不敢直接跟當事人溝通，所以想先透過算命或問 AI 來猜猜看對方在想什麼。(2分)

- [ ] 我完全不想跟當事人講話，我只想依賴玄學單方面告訴我對方是個什麼樣的人、我該怎麼對付他。(1分)

總得分＿＿＿＿＿＿＿＿

【20 - 24 分】理性在線中：可以放心地去丟硬幣、抽塔羅或問 AI 了。這些工具對你來說，只是一種整理情緒的方法，命運的主控權依然緊緊握在你的手上！

【12 - 19 分】半信半疑區：請先踩一下煞車！看看你剛剛在哪幾題拿了 1 分或 2 分？請試著把它們轉化成具體的行動（例如：去設定一個現實驗證的標準，或是直接去跟當事人聊聊）。

【8 - 11 分】大腦關機中：請立刻放下手機或塔羅牌！你現在最需要的不是一個玄學或 AI 的答案，而是讓大腦休息一下，或者找個信任的輔導老師聊聊「客觀的事實」，把理性的濾網補起來再說！

★AI來幫忙★

如果真的遇到難題，請不要問 AI「我該怎麼做？」，試著輸入：

「我是一名大學生，我最近遇到一個選擇困難：【填入你的煩惱，例如：不知道該不該接下社團幹部】。

請你扮演一位客觀的『決策教練』。請絕對不要直接告訴我該怎麼選。

請幫我做兩件事：

列出選擇 A 與選擇 B 各自可能面臨的『最大挑戰』與『潛在收穫』。

問我 2 個關鍵的引導問題，幫助我釐清自己內心最在乎的價值觀是什麼，讓我能自己做出決定。」
