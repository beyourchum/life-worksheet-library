# Ep.99 找不到想走的路？｜你以為自己在找工作，其實你在找想過的生活

**學習目標：** 釐清現階段自己在工作方面最強烈的需求

六種在意：在每個分類裡面，分別有哪些是你在意的事情呢？（六種分類中，最多選出10項）

生活節奏：工作和個人生活間的平衡

- [ ] 完全沒有人打擾的下班時間
- [ ] 固定的生活作息
- [ ] 固定的放假時間
- [ ] 下班後還有運動/從事興趣活動的精神
- [ ] 其他＿＿＿＿＿＿＿＿＿

意義感：工作給自己的意義
☐帶來成就感 ☐工作和夢想相關 ☐做的事情能幫助別人 ☐做的事情可以回饋社會 ☐是少數領域的專家 ☐是別人眼中很酷的工作 ☐其他

成長感：工作給自己的成長
☐能學到新東西 ☐有持續進修的機會 ☐能和領域專家學習 ☐能挑戰新事物 ☐能和不同領域的人交流 ☐其他＿＿＿＿＿＿＿＿＿＿＿＿

資源基礎：工作能給自己的所有人脈、金錢、知識⋯⋯等資源
☐能認識各種領域中的專家 ☐能帶來財富 ☐能帶來名聲 ☐能帶來權力 ☐能提升社會地位 ☐能結交新朋友 ☐其他＿＿＿＿＿＿＿＿＿＿

關係連結：工作場域中的所有人際關係
☐和同事當朋友 ☐沒有人會背刺你 ☐可以提出意見或疑問 ☐主管能考慮現實 ☐上級或同事在遇到困難時可以協助 ☐其他＿＿＿＿＿＿

表現空間：能讓自己的能力派上用場的工作
☐分工明確 ☐工作內容與自己的所學相符合 ☐有自己發揮的空間 ☐擁有主導權 ☐其他

我的排序
從最在意到最不在意，用1~5標出自己目前的需求吧
☐生活節奏：工作內容不會花掉你全部的精神或時間

- [ ] 意義感：工作能帶給你心靈上的滿足

- [ ] 成長感：工作能讓自己在精神或是肉體上有所進步

- [ ] 資源基礎：工作能帶給你籌碼

- [ ] 關係連結：工作中的關係能讓你感到安心、舒適

- [ ] 表現空間：工作能讓你有應用所學、展現能力的空間
