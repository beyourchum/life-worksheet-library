# Ep.115 不是每個人都有一點ADHD｜「網路確診」之後，正常由誰定義？

**學習目標：** 認識自己為什麼卡關

## 01 我卡住了！

請勾選出你在面對不想面對的任務（例如寫期末報告、準備考試）時，最常出現的卡關狀態。

### 執行功能（可複選）

- [ ] 目標很大，不知道怎麼變成任務（例：想把英文變好，卻不知道聽、說、讀、寫中需要加強哪一項，以及要做什麼）
- [ ] 知道任務是什麼，但不知道怎麼開始（例：知道要寫報告，卻不知道從哪裡著手）
- [ ] 其他（請填寫）

### 動機與狀態調節（可複選）

我知道這件事情很重要，但我……

- [ ] 需要有人陪我一起做
- [ ] 需要一點時間壓力
- [ ] 覺得太難了
- [ ] 現在沒有急迫的需求（例如我知道英文很重要，但現在英文不好也活得很好，所以懶得真的去學）

### 感官負荷（可複選）

- [ ] 總是會被其他東西吸引（例：其實沒有很想滑手機，但想透過滑手機逃避寫報告）
- [ ] 旁邊只要有一點聲音，我就沒辦法專心（例：準備專心時，旁邊的所有聲音都會被放大，而且都很吸引我）
- [ ] 其他（請填寫）

## 02 我的新選擇

- [ ] 執行功能
- [ ] 狀態調節
- [ ] 感官負荷

<!-- short-answer: 我目前的進度停在 -->

### 停下來後，我通常會（可複選）

- [ ] 滑手機
- [ ] 發呆
- [ ] 出去玩
- [ ] 睡覺
- [ ] 其他（請填寫）

### 我可以……

請針對你卡關的原因，勾選適合的行動。

### 感官負荷（可複選）

- [ ] 把手機開勿擾模式，放到拿不到的地方
- [ ] 戴上耳塞，或換到安靜的地方
- [ ] 其他（請填寫）

### 動機調節（可複選）

- [ ] 計時八分鐘，時間到了就停下來
- [ ] 把桌面清空，從坐在桌子前面開始
- [ ] 其他（請填寫）

### 執行功能（可複選）

- [ ] 不要想著「寫報告」，先把作業要求貼進文件裡
- [ ] 把題目改寫成三個小標題
- [ ] 其他（請填寫）
