朋友突然說要去看電影跟喝酒，這時候我會⋯⋯

(A) 彈性生活：花錢常跟著當下狀態走，配合度高、享受當下 。（可複選）

- [ ] 沒有特別分配金錢花費

- [ ] 不會特別分析自己的錢花到哪裡了
- [ ] 其他＿＿＿＿＿＿＿＿＿＿

(B) 管理生活：習慣預留分配，花錢前會想「花了之後會不會有問題」 。（可複選）

- [ ] 每個月有固定的預算分配

- [ ] 其他＿＿＿＿＿＿＿＿＿

錢怎麼花？

【情境】社團成發需要一雙皮鞋，這時候我會⋯⋯

(A) 享受資產：買東西傾向選比較好的而非最便宜的，願意讓錢變成生活品質 。

- [ ] 為了好一點的品質，我願意多花錢
- [ ] 注重消費體驗感
- [ ] 相信品牌提供的保障
- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿

(B) 保護資產：買東西傾向選比較便宜的，追求低價格 。

- [ ] 買東西時優先考慮價格
- [ ] 只買必要的東西
- [ ] 其他＿＿＿＿＿＿＿＿

總結：我在（A / B）勾了比較多選項

- [ ] 覺得多付一點錢不算什麼
- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
