# Ep.112 花大錢改善自己，是投資還是浪費？｜《習慣致富》讓消費在日常行動中累積複利

**學習目標：** 把支出變得有意義

## 一、我的狀態

請回想一筆你最近花費、或一直猶豫要不要花的「大筆支出」，並評估它屬於哪一種類型？
☐ 【修復型支出】（為了解決內耗與不舒服）
例子： 戴牙套、心理諮商、看醫生、搬離壓力太大的環境
☐ 【能力型支出】（為了未來的機會）
例子： 買跑得動軟體的新筆電、報名語言課、買專業工具
☐ 【焦慮型支出】（花錢但沒有改變）
例子：買完電子閱讀器之後不拿出來用

想想看，我的修復型支出/能力型支出有沒有帶給我成長或改變？ ☐有 ☐沒有

花錢買的東西/上的課/做的事情，有被我影用在生活中嗎？☐有 ☐沒有

→如果有的話，恭喜你！如果以上都沒有的話，小心修復型支出/能力型支出變成焦慮型支出哦！

## 二、幫消費配上後續

為了不讓剛才的支出變成浪費，請幫消費配上後續行為。這個行為要：有具體動作、有重複的可能、能留下痕跡

我的支出是： ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

具體動作（這筆錢花完，我要怎麼使用 / 照顧它？）：
我決定要 ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

重複的可能：

我會在每週的 ＿＿＿＿＿＿＿＿＿（時間點）執行這件事。

留下痕跡（一個月後，我要留下什麼證據，證明我真的有進步？）：

一個月後，我希望 ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

【範例】

我的支出是：   到診所諮商

具體動作：
我決定要     開始寫情緒日記

重複的可能：

我會在每天的    睡前    執行這件事。

留下痕跡（一個月後，我要留下什麼證據，證明我真的有進步？）：

一個月後，我希望     我可以更清楚的跟諮商師說我的感受

★AI來幫忙★

「我是一名大學生，我最近花了一筆大錢在：【填入你的支出，例如：報名了三個月的日文課 / 買了一台平板電腦 / 開始進行心理諮商】。

我不希望這變成一種『焦慮型支出（買完就沒事了）』，而是希望將它變成『投資自己』的富習慣。

請你扮演習慣設計教練，幫我發想 3 個可以搭配這筆支出的『後續行為』。

這些行為必須同時符合三個條件：

具體（有明確的動詞與小任務）

重複（可以每週輕鬆執行，不會壓力太大）

能留下痕跡（過幾個月後，會有具體的東西或紀錄留下來讓我看見進步）

請用溫和鼓勵的語氣，直接列出這 3 個行動提案讓我選擇。」
