# Ep80. 為什麼會相信匿名網友的雞排之約？

**學習目標：** 在面對誘惑時，能判斷是否接受

## 一、 在一天中，有哪些時刻會讓我覺得好累、好懶得思考，只想躺在床上滑手機？

- [ ] 剛上完課
- [ ] 剛報告完
- [ ] 剛和朋友聚會完
- [ ] 剛下班
- [ ] 發現事情做不完時
- [ ] 和朋友/家人/伴侶吵架
- [ ] 發現錢不夠用時
- [ ] 肚子餓時
- [ ] 身體不舒服時
- [ ] 睡眠不足時
- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

## 二、在這些時刻，我做過哪些事後回想覺得不應該，或是有點後悔的決定？

- [ ] 衝動購物
- [ ] 隨便答應別人的提議
- [ ] 報復性熬夜
- [ ] 暴飲暴食
- [ ] 跟風排隊
- [ ] 其他＿＿＿＿＿＿＿

## 三、 我可以怎麼對抗衝動，「面對前述出現的誘惑的時候，我可以⋯⋯」，選出一個你覺得適合自己的行動

購物慾

- [ ] 想一下我是不是已經有類似的東西？

- [ ] 想一下如果少了這個東西，我的生活會有困難嗎？

- [ ] 看一下餘額，我真的有錢嗎？

- [ ] 看一下行事曆，我有時間一直滑蝦皮/逛街嗎？

- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

朋友的邀約

- [ ] 打開行事曆看一下自己是不是真的有時間

- [ ] 想一下這次的社交會讓我放鬆還是更累？

- [ ] 算一下這次社交會花多少錢，我能負擔嗎？

- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

報復性熬夜

- [ ] 想一下自己明天要幾點起床，這樣的睡眠時長夠嗎？

- [ ] 我明天如果精神不濟，會耽誤事情嗎？

- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

暴飲暴食

- [ ] 我是肚子餓，還是嘴饞？

- [ ] 吃完之後我會不會身體不舒服？

- [ ] 吃完之後我心情會比較好嗎？

- [ ] 現在進食會不會影響我的睡眠？

- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

跟風排隊

- [ ] 這個東西值得我花這麼多時間嗎？

- [ ] 我真的需要這個東西嗎？

- [ ] 如果不花時間排隊，這個時間我會拿來做＿＿＿＿＿＿＿＿＿（什麼事情）

- [ ] 如果這個東西不紅、不流行，我還會想要嗎？

- [ ] 其他＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

★現在我們知道在這些時刻容易做出不適合的決定，記得回到第一大題看看，盡量避免在這些情況下做決定，或是記得利用第三題的行動問問自己哦！★
