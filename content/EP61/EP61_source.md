# Ep.61只有我覺得好笑？對，只有你覺得！｜幽默與冒犯之間的那條線

**學習目標：** 認識開玩笑的時機與場合

評估心理距離：玩笑要跟熟的、互相懂的人開才好笑，你跟這個人熟嗎？

我們認識多久了？

- [ ] 剛認識不到一個月 (1分)

- [ ] 認識幾個月了，算是有點熟悉 (2分)

- [ ] 認識超過半年以上，且持續有聯絡 (3分)

本題得分：( ) 分

我們在哪裡互動？

- [ ] 只在正式場合講話（例如：只在上課、分組報告或社團開會時 (1分)

- [ ] 在正式場合會閒聊，但離開學校/工作後就不太聯絡 (2分)

- [ ] 私底下會約出去玩，或平常下課後會繼續用網路聊天 (3分)

本題得分：( ) 分

我們多常講話？

- [ ] 遇到才會打招呼，平常不會特別聯絡 (1分)

- [ ] 有固定見面的時間，每週大約會聊個一兩次 (2分)

- [ ] 幾乎每天都會講話、傳 LINE 或 IG 互動 (3分)

本題得分：( ) 分

我們都聊些什麼？

- [ ] 只聊公事或課堂上的事（例如：作業寫沒、考試範圍） (1分)

- [ ] 會聊休閒興趣（例如：最近看什麼劇、打什麼遊戲） (2分)

- [ ] 會跟對方抱怨生活、分享心事或私人煩惱 (3分)

本題得分：( ) 分

對方「地雷」的了解程度有多少？

- [ ] 我完全不知道他討厭什麼、或在意什麼 (1分)

- [ ] 我大概知道一些他不喜歡的事，但不是很確定 (2分)

- [ ] 我非常清楚他的「地雷」在哪裡，知道哪些話題絕對不能提 (3分)

本題得分：( ) 分

我們之前的互動氣氛？

- [ ] 我們還沒有互相開過玩笑 (1分)

- [ ] 偶爾開玩笑，但他通常只是禮貌微笑、有點尷尬或不知道怎麼回 (2分)

- [ ] 經常互開玩笑，他會大笑，甚至會開玩笑反擊我 (3分)

本題得分：( ) 分

⚠️ 扣分警報：如果之前開玩笑，對方曾經生氣、已讀不回或氣氛變冷，請直接倒扣 3 分！⚠️

上面 6 題的分數加總起來：＿＿＿＿＿＿＿＿ 分

請根據你的總分，看看你們現在處於哪一個「心理距離」，以及你可以怎麼做：

開玩笑前，請最後問自己一個問題：

「我說出這個玩笑，會讓我們之間的感情變得更好，還是會讓他受傷？」

- [ ] 會變得更好 / 大家會開心笑出來 → 可以說

- [ ] 可能會讓他受傷 / 其實我只是想證明自己很幽默 → 請不要說出口

換句話說

請試著將以下「可能踩雷的玩笑」，改成「共感」或「自嘲（共同的困境）」的說法。

原句： 「笑死考這個樣子，你笑得出來哦？」
改造（共感）： 「這次期中考真的超難，______________________________________＿＿＿＿＿＿＿___！」

原句： 「哎呦又被甩了哦？兄弟是又看上誰了啊？」

改造（自嘲）： 「談戀愛真的好難，像我都_________________________________________。」

請試著舉一個你近期聽到，覺得不太合適的玩笑，也試著改造看看！

原句： 「＿＿＿＿_________________________________________。」

改造： 「＿＿＿＿_________________________________________。」

說錯話了怎麼辦？說了不恰當的玩笑後，記得道歉和關心對方的感受哦！
