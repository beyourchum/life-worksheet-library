# 0001：校正與建置邊界

- 狀態：已採用
- 範圍：學生版學習單

## 決策

學習單在進入本專案前已完成內容初稿。本專案不核對資料庫目標，也不重新設計教材；只校正格式、明確性、可執行性與客群適切性。

Google Docs 是人工來源，Markdown 是 Script 輸入。HTML 由固定題型 parser 與共用範本產生，模型不撰寫 HTML，也不產生需要人工維護的視覺 JSON。

## 理由

既定初稿以單次校正階段處理。把機械工作交給 Script，模型只處理無法用固定規則判斷的文字，可減少重複內容、人工同步與模型用量。

## 後果

- 完整工作流包含 `normalize`、`correct`、`build`、`validate` 與需明確指定的 `publish`；未指定 operation 時不自動發布。
- 可能改變題意、題型或選項的修正仍需人工確認。
- Script 通過不代表實際頁面沒有溢出；交付或發布前須依工作流完成適用的風險分級視覺 QA。A4 列印由固定版型與 Script 檢查驗收，不另要求人工列印 QA。
- Google Sheets 可繼續作搜尋索引，但不是校正依據。
