# HTML 輸出

每份 Script 產生的 HTML 放在 `output/EPxx/EPxx.html`。輸出可重新建立，不直接人工修改；版型或功能問題回到 Markdown、格式契約、共用範本或 Script 修正。

交付或搬移時保留整個 `output/EPxx/` 資料夾，包含 HTML 與同層 `fonts/`，維持相對路徑。只傳 HTML 會缺少本機字型。

本目錄中的檔案是否可交付，依 [工作流的驗證與交付步驟](../workflow/WORKFLOW.md#5-validate) 判定；檔案存在不代表 QA 完成。重建後重新驗證，報告留在 `reports/EPxx/`。
